How it works

Three steps, no learning curve.

Tap the handle

The thin white handle sits on your screen edge, over any app. Tapping it wakes it up.

System volume bar opens

You get Android's native volume panel, same look and feel as pressing a volume key.

It goes inactive

After about 3 seconds the handle shrinks back to a slim, faint line so it stays out of the way.

Questions

What happens when I tap the handle?

Android's own volume bar opens, exactly like pressing a hardware volume key. Use its slider as normal.

Why does it need Accessibility permission?

Android only lets an app draw a touch handle above other apps through an accessibility service. Gesture Volume does not read your screen, keystrokes or messages (content retrieval is switched off).

Does it work if my buttons are fully broken?

Yes, that is the whole point. It talks to Android's audio system directly, so no physical button is involved.

Can I change how long the handle stays active?

Yes. The timeout is a setting in the app, and 3 seconds is the default.

Is it free?

Yes. The app is free, works offline and has no ads inside it. This website shows ads to help cover costs. The source code is viewable on GitHub under its own license.
