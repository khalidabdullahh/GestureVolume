# 🤝 Contributing to GestureVolume

Thank you for your interest in contributing to **GestureVolume**!

GestureVolume is an on-screen circular gesture volume control utility developed and exclusively owned by **Khalid Abdullah**. While the project is source-available and protected against commercial cloning, community contributions such as algorithm optimizations, device compatibility patches, localization, and bug fixes are welcome.

---

## 🛠️ Contribution Workflow

1. **Open an Issue:** Discuss improvements or bug reports first.
2. **Fork the Repo:** Create a fork and a new branch:
   ```bash
   git checkout -b feature/improvement-name
   ```
3. **Commit & Test:** Write clean, modular code and test thoroughly.
4. **Submit a Pull Request (PR):** Describe the change and attach test details.
